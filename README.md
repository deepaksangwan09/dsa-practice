# DSA Practice

Daily C++ DSA problems organized by topic. Each day I will add one problem (by default) with a problem description, approach, and a C++ solution under solutions/<topic>.

Repository layout
- problems/
  - arrays/
  - strings/
  - linked-list/
  - tree/
  - graph/
  - dp/
- solutions/
  - arrays/
  - strings/
  - linked-list/

Contribution rules
- I (Copilot) will add problems daily, default 1 per day, up to 3 if needed.
- Each problem will have a file in problems/<topic>/day-XX.md with title, link (if applicable), paraphrased statement, constraints, examples, and approach.
- Each solution will be in C++ and placed in solutions/<topic>/day-XX.cpp.
- If you want problems from a specific LeetCode user, I can use their public posts/solutions; otherwise I'll pick from common curated lists (NeetCode, Blind75) and LeetCode problemset.
